## Zone Map

- **MC:** Two-layer execution problem — Layer 1 (Format, pattern-shaped, delegable) vs Layer 2 (Fit, judgment-shaped, guarded). Lattice failure mode = treating Layer 1 compliance as proxy for Layer 2. Distribution model spectrum: recommendation-first (TikTok, Reels, YouTube Shorts, Explore) vs follower-first (LinkedIn, X, Instagram Feed/Stories).
- **VG:** Four-axis platform comparison (distribution model / first-class format / dominant voice / engagement signal). Seven failure modes (cross-posting without re-voicing, AI captions unedited, delegated platform-mix, trusted AI trend recs, AI reply engagement, platform-AI defaults, premature "doesn't work" conclusions). Eight-step protocol (platform-mix decision → source content → format-adapt → re-voice → trend check → hook → schedule → read comments).
- **PQ:** Lattice metrics — twelve-minute panel reformatted to four platforms in forty-eight hours; sub-400 views on TikTok/Reels combined over thirty days against eleven-thousand-follower account. TikTok recommendation convergence ~forty minutes of watch behavior (Kabir/Madden FAccT 2023). LinkedIn pivot August 2023 to knowledge-and-advice ranking. X open-source ranking March 2023. Trend half-life: days to small weeks.

## What CAJAL Declines to Architect

- **Four-axis platform comparison table (line 47).** Typography reference table — rows × five platforms with categorical entries (distribution model, first-class format, optimal length, dominant voice, engagement signal, AI good at, AI bad at). Belongs in the type system. A figure version would require platform logos or rendered names and would age within months. Render as a textual table with a "snapshot as of late 2025" footer.
- **Delegate List table (line 57).** Typography table — task / why pattern-shaped / AI tool category / time saved / quality risk. Five-column reference grid. Not figure-shaped.
- **Guard List table (line 65).** Typography table — task / why judgment-shaped / what goes wrong if delegated / required human role / escalation trigger. Same structural reason as the Delegate List.
- **Platform UI screenshots, app icons, vendor logos.** Categorical CAJAL exclusion across the chapter. Any visual that would naturally call for a TikTok logo, Reels frame, or LinkedIn post mockup is rejected — it ages fast and pulls the figure into vendor territory.
- **The seven failure modes (lines 124–137).** Prose list with concrete examples; reads better as numbered text than as an icon grid. A figure version would either be redundant with the two-layer diagram (Figure 9.1) or descend into seven labeled icons that age with the platforms.
- **The eight-step protocol (lines 103–119).** Already sequenced clearly in prose. A flowchart version would be a typography exercise dressed as a figure. If readers want a visual anchor, the figure they need is Figure 9.1; the protocol is the operationalization of it.
