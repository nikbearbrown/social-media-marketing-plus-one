## What CAJAL Declines to Architect

- **Forecast track-record summary table (line 41).** Typography reference table — rows (capability-timing, scope, structural) × columns (pattern, overshot example, undershot example, what held up). The categorical content is well-suited to text presentation. A figure version would render as a 3×4 cell grid that reads better as a table.
- **Sample forecast register (line 87).** Typography reference table — claim / label / probability range / horizon / falsifiers / move conditions / review date. Seven columns with categorical entries. Reference material for readers building their own registers; belongs in the type system or in an appendix template.
- **Strategist-vs-planner forecast pair (chapter opening).** The two-character opening case is prose narrative. A figure version (two timeline arrows showing where each was wrong) would over-formalize a rhetorical device that earns its weight from the narrative pairing.
- **METR time-horizon doubling.** Tempting to plot the doubling curve. Declined: the chapter explicitly cautions "that is one data point, not a law." Rendering the curve would invite the reader to treat the trend as more established than the source warrants. The Figure 11.2 capability-bound curve handles the same conceptual territory at the right level of abstraction.
- **Scaling-laws curves.** Kaplan et al. and Chinchilla loss-vs-compute curves are tempting. Declined for the same reason — the chapter explicitly distinguishes loss curves from real-world capability and rendering the loss curves would invite the elision the chapter is warning against.
- **Eloundou exposure heatmap.** Even more tempting. Declined: the chapter is making a point about how the trade press dropped the "exposure" distinction; a figure that ranked task categories by exposure would reproduce the elision the chapter critiques.

## Split-point note

The capability-bound / attribution-bound distinction in Figure 11.1 and the durable / decaying layers in Figure 11.2 must remain visually consistent — the same Vermillion that codes "Guard" in Figure 11.1's terminal quadrants should code the attribution-bound layer in Figure 11.2. Verify Chapter 12 (the +1 Practice) uses the same canon for the Delegate/Guard cadence figures.

The forecast register table that this chapter declines to render as a figure should appear as a typography template in an appendix or in a downloadable resource — readers will want to copy it. Note in the production manifest that the table should travel with the chapter in any digital edition.

Coordinate Figure 11.2's decay-curve treatment with Chapter 9's aging-risk visual convention (the Vermillion exclamation marker on the platform spectrum). Both figures are saying "this layer ages" but at different time scales — Chapter 9 ages on months, Chapter 11 on years. If the visual conventions diverge arbitrarily, the reader will lose the rhyme.
